# design system — thyanri profile

## palette

| role          | hex       | usage                                      |
|---------------|-----------|---------------------------------------------|
| background    | `#323437` | page / card backdrop                        |
| surface       | `#2c2e31` | elevated cards, panels, hero fills          |
| primary text  | `#d1d0c5` | headings, body copy                         |
| muted text    | `#646669` | secondary labels, metadata, descriptions    |
| accent        | `#e2b714` | highlights, active indicators, accent bars  |
| subtle line   | `#3a3d41` | borders, dividers, grid lines               |

## typography tone

- system sans-serif stack: `'Segoe UI', 'SF Pro Display', system-ui, sans-serif`
- headings: semi-bold 600, letter-spacing 0.5–1px
- body / labels: regular 400, letter-spacing 0.3–0.5px
- prefer lowercase for section labels and metadata
- avoid all-caps except in very short tags

## spacing

- generous vertical whitespace between sections
- hero: full-width, 200px height
- content max-width: ~840px (matches hero)
- section gaps: 32–48px equivalent in markdown (`<br>` or blank lines)
- inner padding in panels: 16px minimum
- accent bars: 2–3px wide, subtle opacity

## design rules

1. **no visual clutter** — every element must earn its place
2. **restrained accent use** — accent color for small indicators only, never large fills
3. **local assets first** — prefer SVGs in `/assets` over third-party badge services
4. **breathing room** — if it feels tight, add space
5. **dark-first** — all visuals assume dark background
6. **no emoji spam** — use sparingly if at all, never as decoration
7. **no rainbow badges** — one accent color, one muted palette
8. **collapsible by default** — secondary details go inside `<details>` blocks
9. **product language** — write like an interface, not a blog post
10. **consistency** — new elements must reference this palette and follow the spacing logic

## svg conventions

- viewBox width: 840 for full-width, 260 for cards
- round corners: 4–6px on cards
- stroke-width for borders: 0.5–1px
- gradients: subtle, low-opacity fades only
- grid patterns: 40px spacing, 0.4 opacity
